# AhorrApp

## Descripción
Aplicación web para la gestión de ingresos y gastos personales, permitiendo calcular el saldo disponible en tiempo real.

## Tecnologías
- JavaScript
- HTML
- CSS

## Funcionalidades
- Registro de ingresos
- Registro de gastos
- Cálculo automático del saldo

## Cómo usar
1. Ingresa un monto
2. Selecciona ingreso o gasto
3. Visualiza el saldo actualizado
